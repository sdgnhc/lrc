JavaScript 程序结构

三大程序结构：顺序、条件（分支）、循环。点击按钮即可实时运行。

1. if...else if...else: 成绩等级

if (score >= 90) { grade = "优秀"; }
else if (score >= 80) { grade = "良好"; }
else if (score >= 60) { grade = "及格"; }
else { grade = "不及格"; }
等待输入...

2. switch: 数字转星期

switch (day) {
  case 1: week = "星期一"; break;
  case 2: week = "星期二"; break;
  ...
  default: week = "输入无效";
}
等待输入...

3. 循环结构：for 循环

for (let i = 1; i <= 10; i++) {
    // 循环执行代码
}
